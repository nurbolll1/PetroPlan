# лист. — планировщик покупок

Простой адаптивный сайт для планирования покупок на 4 недели, с ценами в тенге и расчётом калорий и БЖУ.

## Запуск

Откройте `index.html` в браузере. Для локальной разработки можно запустить статический сервер, например `python -m http.server 8000`, и перейти на http://localhost:8000.

## Возможности

- Каталог продуктов, поиск и редактирование товаров
- Недельные корзины и месячный бюджет
- Расчёт КБЖУ по количеству продуктов
- Добавление своих продуктов и цен
- Импорт товаров из CSV, экспорт закупок и резервная копия JSON
- Автоматическое сохранение в `localStorage` текущего браузера

## Данные и ограничения

**Цены в начальном каталоге — примерные, не актуальный прайс «Семейного».** КБЖУ — справочные значения; для фасованных товаров сверяйте этикетки. Автоматического подключения к магазину сейчас **нет**.

Данные сохраняются только в браузере на устройстве пользователя. Они не синхронизируются между телефонами и компьютерами. Не очищайте данные сайта без экспорта резервной копии.

Формат CSV: `name,category,unit,price,kcal,protein,fat,carbs`. Для единиц `кг` и `л` КБЖУ указываются на 100 г/мл, для `шт` — на штуку. Цена — за 1 кг, 1 л или 1 шт.

## Публикация на GitHub Pages

В репозитории есть workflow `.github/workflows/deploy-pages.yml`, который собирает статический сайт из корня репозитория и публикует его при push в `main`.

1. Откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Объедините PR в `main`. Workflow опубликует сайт по адресу `https://nurbolll1.github.io/PetroPlan/` **при условии, что тариф и настройки репозитория разрешают GitHub Pages**.
4. Статус смотрите во вкладке **Actions**.

Репозиторий сейчас приватный. На некоторых тарифах GitHub Pages для приватных репозиториев недоступен. В таком случае можно сделать репозиторий публичным или выбрать другой статический хостинг; изменение видимости требует отдельного решения владельца.

## Планы

- Подключение согласованного источника актуальных товаров/цен «Семейного»
- Источники достоверных значений КБЖУ
- Синхронизация списков между устройствами через сервер и базу данных
- Удобная публикация обновлений
