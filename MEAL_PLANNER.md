# «лист.» — генератор меню и подключение ИИ

На GitHub Pages работает режим **«Умный подбор»** без сервера. Вкладка «План питания» принимает бюджет в тенге, число людей, 3/5/7 дней, 2/3 приёма пищи, личный ориентир ккал на человека в день и исключаемые продукты. Отчёт показывает примерные калории, белки, жиры и углеводы на человека по дням, а также предупреждение о расхождении с ориентиром. Результат: список покупок, ориентировочная цена, рецепты и добавление товаров в выбранную неделю. Расчёт основан на ценах твоего каталога, а не ценах «Семейного» в реальном времени.

**Это не языковая модель.** Для настоящего ИИ есть отдельный режим, требующий HTTPS API.

## Подключение облачного ИИ (пример)

Файл `examples/ai-worker.js` — пример сервера для Cloudflare Workers. Создай Worker в Cloudflare, вставь туда содержимое файла, укажи секрет `OPENAI_API_KEY` (через Secrets, **никогда в GitHub или HTML**), настрой модель через `OPENAI_MODEL`, если нужно. В браузере на вкладке «План питания» выбери «ИИ» и вставь URL Worker.

**До публичной публикации обязательно настроить ограничения запросов, защиту от ботов и лимит расходов** (Cloudflare WAF/Rate limiting, OpenAI project budget). Проверка Origin не является защитой от посторонних запросов и расходов; это лишь ограничение CORS. Публично развернуть Worker без защиты нельзя. Реальный AI Worker в репозитории не развёрнут и API-ключ не настроен.

Проверяй рецепты и стоимость: модель может ошибаться, а товары и цены приблизительные. Сервер возвращает JSON с `rows`, а браузер дополнительно проверяет ID товаров, количества и сумму заказа.

## Как пользоваться

1. Открой «План питания» в меню.
2. Введи бюджет на указанный срок, людей и дни.
3. Выбери исключаемые продукты через запятую.
4. Нажми «Составить план»; можно раскрывать ингредиенты и шаги приготовления.
5. Нажми «Добавить в неделю» либо «Скачать список и меню». Новые количества прибавятся к уже выбранным товарам.
